## Selected repositories

### [Who Gets Heeded?](https://github.com/brucefjn/who-gets-heeded)
Research on responsiveness in EPA rulemaking, using an LLM-assisted, obligation-level framework and blind human audits. I formulated the research question and led the research.

Jianing Fan and Yue Yao — co-first authors; equal contribution. Accepted full paper and oral presentation, ACM EAAMO 2026. [Read paper](https://arxiv.org/abs/2608.10329).

### [DistilBERT sentiment analysis](https://github.com/brucefjn/ML-Sentiment-Analysis-)
A course project on movie-review classification with fine-tuned DistilBERT, an interactive prediction prompt, and examination of failure cases involving sarcasm and negation.
